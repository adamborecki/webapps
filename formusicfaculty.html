Built with a Coding Agent

Cool, helpful, educational web apps for music faculty, and how to make your own.

Adam Borecki borecki@chapman.edu

How AI is involved

You use AI to create the web app. No additional AI is used by students when they use the app.

These particular web apps were built with Claude Code.

How to open one

Point your phone's camera at a square code, then tap the link that pops up. Or type the address under each app into any browser.

Assign homework that's interactive

When I assign one of these as homework, students do it on the website. When they're done, they click a button to get a Canvas code, then copy and paste it into Canvas, which is how I handle grading. No grading data is saved inside the web app itself.

How to try it yourself

  1. Open an AI you pay for, or Chapman's PantherAI at pantherai.chapman.edu.
  2. If you're using PantherAI, open the model picker and choose Anthropic › Claude › Sonnet (pick the highest number available).
  3. Paste this in, choosing one of the three levels:
    Help me build a webapp using GitHub Pages. I'm a beginner intermediate advanced at music tech.
